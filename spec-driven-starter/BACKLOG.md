# Backlog

Ideas and tasks that don't have a spec yet, in priority order (top = next). Each item is sized to one session
(1–2 h) and has a "done when" line. When an item grows beyond one session or changes behaviour, give it a spec
in `specs/product/` and move it off this list.

- [ ] **Item title**: what and why, in one line.
  Done when: an observable result.
